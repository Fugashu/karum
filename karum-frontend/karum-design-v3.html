Rules 05
✓ DO

KARUM is always all-caps, Space Mono 700, letter-spaced. The amber A is optional but preferred on dark backgrounds.

✗ DON'T

Never write "Karum" in mixed case in the UI. The Kārum diacritical only appears in historical pitch copy.

✓ DO

Keep clear contrast between background (#0f0f0f) and cards (#1c1c1c). The 12-step jump ensures everything is readable.

✗ DON'T

Never use backgrounds darker than #0f0f0f or cards lighter than #1c1c1c. The range is tight on purpose.

✓ DO

Body text is always DM Sans at 16px minimum. Monospace data can be smaller (11px) because it's always numbers, which are inherently more legible.

✗ DON'T

Never set body paragraphs in Space Mono. It's great for data and labels, but walls of monospace text are fatiguing.

✓ DO

Use sharp corners everywhere. Buttons, cards, inputs, badges — all 0px border-radius. Fuel bars and status dots are the only round elements.

✗ DON'T

Never add border-radius, soft shadows, gradient fills, blur effects, or glow (except the subtle green glow on the online status dot).
